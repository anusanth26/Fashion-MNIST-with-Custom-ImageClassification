# 👗 Fashion MNIST - Custom Image Classification

A simple image classifier trained on the Fashion MNIST dataset using a neural network model built in TensorFlow/Keras. The project also supports predicting custom images provided by the user.

---

## 🧠 Model Summary

- **Dataset**: Fashion MNIST (60,000 training + 10,000 test images)
- **Image Size**: 28x28 grayscale
- **Classes**: 10 (e.g., T-shirt, Trouser, Pullover, etc.)
- **Framework**: TensorFlow/Keras
- **Custom Input**: Accepts external user-uploaded images for prediction
